# 学习任务 Spec 模板

基于"非代码任务 Spec 驱动模式"的通用学习任务模板，提供**两种变体**适应不同内容类型。

## 两种变体

| 变体 | 六维度 | 适用内容 | 典型场景 |
|------|--------|----------|----------|
| **教程类**（默认） | 概念→原理→案例→结论→自测→框架 | 叙事型内容 | 教程、课程、博客、论坛帖 |
| **技术文档阅读** | API表面积→架构决策→用法模式→约束评价→Cheatsheet→API地图 | 参考型内容 | API 文档、框架文档、RFC、技术规范 |

### 变体对比

```
教程类（叙事型）                      技术文档阅读（参考型）
─────────────────────────          ─────────────────────────
1. 核心概念定义           ──►        1. API 表面积概览
   "这是什么？"                         "有哪些接口可用？"

2. 技术原理与机制         ──►        2. 架构与设计决策
   "怎么工作的？"                       "为什么这样设计？"

3. 实践案例与应用         ──►        3. 用法模式与最佳实践
   "怎么用？"                          "怎么用才对？"

4. 关键结论与个人理解     ──►        4. 约束与边界条件 + 设计评价
   "学到了什么？"                       "有什么坑？设计好吗？"

5. 自测问答               ──►        5. 快速参考卡（Cheatsheet）
   "我真的会了吗？"                     "怎么快速查到？"
                                       （表格 + Mermaid 图）

6. 知识框架思维导图       ──►        6. API 地图/概念关系图
   "知识全景是什么？"                   "谁依赖谁？"
```

## 快速使用

```bash
# 1. 复制模板
cp -r .trae/specs/_templates/learning-task/ .trae/specs/<change-id>/

# 2. 选择变体
# 教程类：使用 spec.md 上方默认 Requirements
# 技术文档：使用 spec.md 底部「变体：技术文档阅读」Requirements，删除默认部分

# 3. 替换占位符
# {TOPIC} → 学习主题名称
# {SOURCE_URL} → 学习来源（URL/书名/文档路径）

# 4. 开始执行
```

## 适用场景

| 变体 | 场景 | 示例 |
|------|------|------|
| 教程类 | 在线教程/博客 | 论坛教程、技术博客文章 |
| 教程类 | 书籍/论文研读 | 技术书籍章节、学术论文 |
| 教程类 | 视频/课程学习 | 在线课程、技术演讲 |
| 技术文档 | API 文档阅读 | REST API、GraphQL Schema、SDK 文档 |
| 技术文档 | 框架/库文档 | React、FastAPI、Pandas 等框架文档 |
| 技术文档 | 技术规范 | RFC、W3C 标准、语言规范 |
| 技术文档 | 配置/部署文档 | Docker Compose 参考、K8s 资源定义 |

## 不适用场景

- 简单查询（如"XX 命令怎么用"）→ 直接回答
- 仅需阅读不需产出的浏览 → 不需要 Spec
- 产出维度少于 3 个的轻量学习 → 可用自由模式

## 模板文件

| 文件 | 内容 | 需要修改 |
|------|------|----------|
| `spec.md` | 两种变体的 Requirements 定义 | 选择变体 + 替换 `{TOPIC}` 和 `{SOURCE_URL}` |
| `tasks.md` | 两种变体的 Tasks + 依赖关系 | 选择变体 + 按需调整子任务细节 |
| `checklist.md` | 两种变体的检查点 | 选择变体 + 按需增删检查项 |

## 执行流程

```
/spec 命令 → 选择变体 → 创建 Spec → 审批 → 实现 Task 1~6 → 验证 Checklist → 复盘导出
```
