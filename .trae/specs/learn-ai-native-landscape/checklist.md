# Checklist

> 模板：learning-task | 教程类变体

## 核心概念（Task 1）
- [x] 核心概念数量不少于 5 个
- [x] 每个概念有清晰的定义和解释
- [x] 概念间无混淆或重复
- [x] 覆盖：AI Native Landscape、AI 原生技术栈、策展式收录、项目墓地、综合健康度评分、参考状态

## 技术原理（Task 2）
- [x] 评分模型 4 维度（活跃度/社区参与度/影响力/持续性）阐述清晰
- [x] 项目生命周期与参考状态流转机制说明完整
- [x] 至少包含 1 张 Mermaid 图表（flowchart/sequence/state）
- [x] 收录/变更/归档三流程的触发条件与协作关系清晰
- [x] 图表与文字说明一致，无矛盾

## 实践案例（Task 3）
- [x] "提交项目"操作步骤归纳完整（GitHub Issue 表单流程）
- [x] "变更项目"操作步骤归纳完整（PR + YAML + validate）
- [x] "归档项目"触发条件与恢复机制明确
- [x] 8 大分类与子类生态结构梳理完整
- [x] 使用场景案例（按域浏览/按评分筛选/按状态判断）具备可复现性

## 关键结论（Task 4）
- [x] 结论数量在 5-8 条之间
- [x] 结论覆盖学习内容的主要维度（价值主张/收录哲学/评分透明性/生态趋势/维护模式）
- [x] 个人理解具有可迁移性（提炼了至少 1 个可迁移模式）
- [x] 结论有原文依据支撑，非主观臆断
- [x] 包含 AI 原生生态与云原生生态的对比整合

## 自测问答（Task 5）
- [x] 题目数量在 5-10 之间
- [x] 题目覆盖核心知识点的主要维度（定位/收录/分类/评分/状态/流程/信任）
- [x] 每题答案准确、完整
- [x] 题目难度有层次（基础 + 进阶）

## 知识框架（Task 6）
- [x] 使用 Mermaid mindmap 格式
- [x] 覆盖全部学习模块（定位/收录边界/分类体系/评分模型/参考状态/流程/趋势）
- [x] 层级关系正确，无逻辑错误
- [x] 一眼可看清知识全貌

## 整体质量
- [x] 学习笔记结构完整（六维度齐全）
- [x] 无事实性错误
- [x] 语言专业、客观、简洁
- [x] 三个来源（关于页/主页/评分方法页）信息整合无冲突
