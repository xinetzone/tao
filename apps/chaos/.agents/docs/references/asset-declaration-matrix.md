# 声明但缺失资源治理决策矩阵

## 背景

静态站点中常见两类"声明但缺失"问题:
1. **HTML 声明引用但文件不存在**:如 `@font-face` 声明了字体文件路径,但文件实际缺失
2. **CSS/JS 声明引用但文件不存在**:如 `<script src>`、`<link href>` 引用了不存在的文件

这类问题不会导致页面完全无法加载(浏览器会回退),但会产生 404 错误,影响页面质量评分与用户体验。

## 决策矩阵

| 补全成本 | 移除成本 | 视觉/功能影响 | 建议方案 | 优先级 |
|---|---|---|---|---|
| 高(>5MB 或 License 风险) | 低(改几行代码) | 无(有回退链) | **移除声明**(最优) | 高 |
| 高 | 低 | 有(无回退链) | 补全资源或加回退链 | 高 |
| 低 | 低 | 无 | 移除声明(简化) | 中 |
| 低 | 低 | 有 | 补全资源 | 高 |
| 低 | 高(多处引用) | 无 | 补全资源 | 中 |
| 低 | 高(多处引用) | 有 | 补全资源 | 高 |
| 任意 | 任意 | 有(无回退链) | 补全资源或加回退链 | 高 |

## 补全成本评估维度

| 维度 | 低成本 | 高成本 |
|---|---|---|
| 文件体积 | <1MB | >5MB |
| License | MIT/Apache/BSD | GPL/未知/商业 |
| 获取难度 | CDN/官方下载 | 需购买/需授权 |
| 维护负担 | 单文件 | 多文件/有依赖 |

## 移除成本评估维度

| 维度 | 低成本 | 高成本 |
|---|---|---|
| 引用点数 | 1 处 | >3 处 |
| 引用位置 | 单一 HTML | 多 HTML/CSS/JS |
| 关联代码 | 无 | 有 JS 逻辑依赖 |

## 视觉/功能影响评估

| 场景 | 影响评估 | 判定 |
|---|---|---|
| 字体缺失 + 有系统字体回退链 | 视觉差异极小 | 无影响 |
| 字体缺失 + 无回退链 | 使用浏览器默认字体 | 有影响 |
| JS 库缺失 + HTML 未引用 | 无影响 | 无影响 |
| JS 库缺失 + HTML 引用 | 功能失效 | 有影响 |
| 图片缺失 + 有 alt 属性 | 显示 alt 文本 | 轻微影响 |
| 图片缺失 + 无 alt 属性 | 显示破损图标 | 有影响 |

## 实际案例

### 案例 1:react-survey 字体缺失(P7)

| 维度 | 评估 |
|---|---|
| 补全成本 | 高(NotoSansSC 完整字符集约 10MB/文件,2 文件共 ~20MB) |
| 移除成本 | 低(改 10 行 CSS,1 处引用) |
| 视觉影响 | 无(font-family 回退链覆盖主流平台) |
| **决策** | **移除声明** |
| **结果** | 零体积消除 404,视觉无差异 |

### 案例 2:echarts.min.js 未引用(P4 清理)

| 维度 | 评估 |
|---|---|
| 补全成本 | 不适用(文件存在但未被引用) |
| 移除成本 | 低(删除文件,HTML 无需改动) |
| 视觉影响 | 无(HTML 未引用) |
| **决策** | **删除文件** |
