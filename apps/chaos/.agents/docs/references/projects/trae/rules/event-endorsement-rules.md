# 赛事背书阵容设计规则

> **来源**：萃取自 TRAE AI 创造力大赛「领造官 × 评委团」双轨结构  
> **适用场景**：任何需要设计代言人 + 评审阵容的赛事/活动

---

## 规则 1：领造官多元叙事覆盖

**定义**：领造官 ≥ 3 人，每人代表一个不同的「为什么重要」叙事角度。

**反面案例**：4 个领造官全是技术背景 → 只覆盖"这能跑通"，丢失"这能表达""这能卖出去""这能重塑行业"三个叙事。

**TRAE 正面案例**：

| 人数 | 叙事角度 | 回答的问题 |
|------|----------|-----------|
| 胡彦斌 | 创意能否被表达 | "AI 不是冷冰冰的代码，是新的表达媒介" |
| 罗永浩 | 产品能否走向市场 | "Demo 能不能变成普通人愿意用的商品" |
| 楼天城 | 技术能否跑通 | "作品经得起工程判断，真的能用" |
| Tim | 工具能否重塑创作 | "策划→脚本→素材→后期→分发，每一步都被 AI 重塑" |

**自检**：
- [ ] 领造官人数是否 ≥ 3？
- [ ] 是否覆盖了「表达」「市场」「工程」至少三个叙事角度？
- [ ] 是否存在两个领造官代表同一个叙事角度（冗余）？

---

## 规则 2：评委数量按比例配置

**定义**：评委 ≥ 领造官 × 1.5 人，确保每个叙事角度都有对应的技术验证覆盖。

**反面案例**：4 个领造官 + 4 个评委 → 可能出现某个叙事角度没有对应评委能验证。

**TRAE 正面案例**：4 领造官 × 1.5 = 6 人最低 → 实际 7 评委，每个叙事角都有 1-2 名评委对应：

| 叙事角度 | 领造官 | 对应评委 | 验证维度 |
|----------|--------|----------|----------|
| 创意表达 | 胡彦斌 | 快刀青衣 | 内容产品 / 用户增长 |
| 产品市场 | 罗永浩 | 胡宇航 | 产品创新 / 技术落地 |
| 技术工程 | 楼天城 | 洪定坤 + 李东江 | 技术战略 / 工程体系 / 开发工具链 |
| 内容创作 | Tim | 王兴兴 | 硬件交互 / 具身智能 |

**自检**：
- [ ] 评委人数是否 ≥ 领造官人数 × 1.5？
- [ ] 每个领造官代表的叙事角度是否至少有 1 名评委可以验证？
- [ ] 是否存在某个叙事角度没有评委覆盖（盲区）？

---

## 规则 3：身份不重叠

**定义**：领造官与评委的身份不能重叠。代言归代言，评审归评审。

**反面案例**：领造官同时担任评委 → 自己代言自己评审，公信力崩塌。

**自检**：
- [ ] 领造官名单 ∩ 评委名单 = ∅？
- [ ] 是否存在同一人或同一机构的双重身份？

---

## 规则 4：缺失映射解读

**定义**：有评委但无对应领造官的维度 = 长期布局而非当前叙事重点。

**TRAE 案例**：张俊波（3D/平台生态）、张鑫（云基础设施）有评委覆盖但无对应领造官 → 这些维度在评委体系中被考虑，但不是当前对外叙事的主线。

**自检**：
- [ ] 是否列出了所有「有评委但无领造官」的维度？
- [ ] 是否明确了这些维度是「长期布局」而非「被遗忘」？
