# experiences — 经验类记忆

> **维护责任人**：Leader Agent

## 模块功能

本模块存储从具体实践中提炼的经验类记忆，记录文档维护流程、知识图谱构建等实战方法，帮助降低未来类似任务的执行成本。

## 使用方法

- **何时查阅**：当你需要执行文档维护、构建知识图谱或学习历史实战经验时
- **如何引用**：使用相对路径引用，如 `[文档维护5步流程](./2026-05-25-doc-maintenance-5-steps-experience.md)`

## 依赖关系

- 引用外部：常引用 [`../principles/`](../principles/README.md) 中的设计原则作为经验总结的理论基础
- 被引用：[`../methodologies/`](../methodologies/README.md) 中的方法论可能总结多条经验
