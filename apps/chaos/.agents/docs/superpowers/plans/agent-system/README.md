# agent-system — 智能体系统计划

> **维护责任人**：Leader Agent

## 模块功能

本模块存储与智能体系统设计、协作机制、记忆协议相关的计划，涵盖协作元模型、做梦协议、角色评审工作流、上下文结构优化与 Token 减量等主题，为智能体协作与运行效率提供设计蓝图。

## 使用方法

- **何时查阅**：当你需要设计或调整智能体协作机制、记忆回流协议、角色评审流程、上下文优化策略时
- **如何引用**：使用相对路径引用，如 `[协作元模型计划](./2026-05-24-agent-collaboration-metamodel/index.md)`
