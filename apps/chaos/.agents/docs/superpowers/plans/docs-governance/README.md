# docs-governance — 文档治理计划

> **维护责任人**：Leader Agent

## 模块功能

本模块存储与文档治理相关的计划，包括初始化引导产出、记忆模块化重构、道业务映射框架等，为文档体系的治理、模块化与业务对齐提供设计依据与执行方案。

## 使用方法

- **何时查阅**：当你需要规划文档治理策略、设计模块化重构方案、构建业务映射框架时
- **如何引用**：使用相对路径引用，如 `[道业务映射框架计划](./2026-05-23-dao-business-mapping-framework/index.md)`

## 依赖关系

- 被引用：[`../agent-system/`](../agent-system/README.md) 中的协作元模型常引用本模块的治理框架作为约束来源
