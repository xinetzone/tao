# 审计报告模块

> **维护责任人**：Leader Agent

## 模块功能

存放针对知识库、文档目录与治理体系的系统性质量审计报告，包含债务分类、发现清单、自动化审计矩阵与行动计划，用于驱动治理资产的持续改进。

## 使用方法

- **何时查阅**：需要评估知识库质量、识别记忆债务、规划治理行动、参考审计方法论时查阅
- **如何引用**：使用相对路径引用，如 `[superpowers 记忆债务审计](./audit-report-superpowers-memory-debt-20260611/index.md)`

## 依赖关系

- 引用 `retrospective-conventions.md`、`documentation.md`、`rule-evolution.md` 等治理规范
- 关联 `project-reviews/`（审计结论汇入项目级复盘）
- 关联 `task-summaries/documentation/`（治理行动落地为任务总结）
