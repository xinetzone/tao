# 其他复盘模块

> **维护责任人**：Leader Agent

## 模块功能

存放不属于项目级复盘、审计报告、洞察报告、会话复盘、任务总结等标准分类的其他复盘内容，包括外部内容创作、归档操作复盘与推广活动总结等。

## 使用方法

- **何时查阅**：需要回顾外部内容创作过程、归档操作复盘、推广活动执行情况时查阅
- **如何引用**：使用相对路径引用，如 `[微信文章归档复盘](./wechat-archive-and-commits-summary-20260623.md)`

## 依赖关系

- 关联 `insights/`（部分复盘含洞察萃取）
- 无其他外部依赖
