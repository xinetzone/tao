# 项目级复盘模块

> **维护责任人**：Leader Agent

## 模块功能

存放 AgentForge 项目阶段性、增量式与月度级别的全面复盘报告，覆盖项目目标达成度、执行过程、风险问题、成果质量、团队协作等核心维度的系统性回顾与方法论沉淀。

## 使用方法

- **何时查阅**：需要了解项目阶段性整体进展、回顾关键里程碑达成情况、评估技术债务与风险演变、提炼可复用经验时查阅
- **如何引用**：使用相对路径引用，如 `[AgentForge 项目复盘](./agentforge-project-retrospective-20260523/index.md)`

## 依赖关系

- 引用 `retrospective-conventions.md`（复盘规范）
- 关联 `task-summaries/`（任务级复盘为项目级复盘提供素材）
- 关联 `audit-reports/`（审计结论作为项目复盘输入）
