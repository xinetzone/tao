# 会话复盘模块

> **维护责任人**：Leader Agent

## 模块功能

存放单会话级别的复盘报告，聚焦于一次完整对话会话内的任务执行全周期回顾，包含执行概览、过程记录、关键决策与改进建议。

## 使用方法

- **何时查阅**：需要回顾单次会话执行过程、评估会话级任务效率、提炼会话级经验时查阅
- **如何引用**：使用相对路径引用，如 `[文档治理全周期会话复盘](./session-retrospective-doc-governance-full-cycle-20260611.md)`

## 依赖关系

- 关联 `task-summaries/documentation/`（会话复盘对应任务总结）
- 关联 `audit-reports/`（部分会话涉及治理审计）
