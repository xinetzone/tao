# AI 工具 GTM 策略建议 — 基于四工具竞品洞察

> **来源**：Cursor / Bolt.new / Replit / Trae 四工具运营动作对比 + TRAE 大赛研究项目  
> **使用方式**：按当前阶段对号入座，选择匹配的策略组合

---

## 一、先判断：你处于哪个阶段

| 阶段 | 用户规模 | 核心目标 | 参考对标 |
|------|----------|----------|----------|
| **早期** | 0-10w | 建立认知、积累种子用户 | Cursor 早期策略 |
| **中期** | 10w-100w | 商业化验证、企业客户切入 | Bolt 模式 |
| **后期** | 100w+ | 生态锁定、品牌升级 | Trae 赛事模式 |

---

## 二、早期（0-10w）：KOL 证言 + 社交病毒

### 核心策略

```
获客 = KOL 证言（信任） + 技术博客（权威） + 社交病毒（传播）
```

### 具体动作

| 动作 | 参考案例 | 预算 | 优先级 |
|------|----------|------|--------|
| 获取 1-2 位行业技术大佬公开推荐 | Cursor：Stripe Patrick、Karpathy 推荐 | 低（关系资源） | P0 |
| 启动技术博客，每月 ≥ 2 篇深度内容 | Cursor Changelog（8-10篇/年） | 低 | P0 |
| 社交媒体病毒传播：Demo 视频、对比评测 | Cursor Twitter 策略 | 低 | P1 |
| 入驻开发者社区（Hacker News / Reddit / V2EX） | Cursor 早期社区策略 | 低 | P1 |

### 关键原则

- **零奖金时期**：Cursor 没花一分钱奖金拿到 9 位大佬背书
- **博客 > 广告**：技术博客是长期信任资产，广告费用花完就没了
- **Demo 即广告**：一个 30s 的惊艳 Demo 视频胜过 10 篇软文

---

## 三、中期（10w-100w）：企业案例 + 定价验证

### 核心策略

```
商业化 = 企业案例（证明价值） + 分层定价（筛选用户） + 功能独占（逼升级）
```

### 具体动作

| 动作 | 参考案例 | 预算 | 优先级 |
|------|----------|------|--------|
| 争取 2-3 个知名企业客户并公开案例 | Bolt：Porsche / Material / WAPO | 中 | P0 |
| 设计 3-4 档定价（免费/个人/团队/企业） | Cursor：Hobby→Pro→Pro+→Ultra | 低 | P0 |
| 将核心功能设为 Pro 独占 | Bolt：Max 模型 "98% 少错" 特权 | 低 | P1 |
| 建立设计系统/模板市场 | Bolt Examples 策略 | 中 | P1 |
| 获取 SOC 2 等安全认证 | Cursor 企业渗透前提 | 高 | P2 |

### 定价参考

| 层级 | 价格参考 | 核心权益 | 目标用户 |
|------|----------|----------|----------|
| 免费 | $0 | 基础功能 + 限速 | 个人试用 |
| Pro | $20/月 | 无限制 + 高级模型 | 重度个人 |
| Team | $40/月 | 协作 + MCP + SSO | 小团队 |
| Enterprise | 定制定价 | 私有部署 + 审计 | 大企业 |

### 关键原则

- **Pro 功能独占必须恰当**：Bolt 的 "98% 少错" 让用户觉得 "值得"，但要让免费用户觉得 "够用"
- **企业案例优先于广告**：Porsche 用一个案例撬动了整个车企行业
- **定价分档间距要明显**：$0→$20→$40 每档差异必须直观可感知

## 四、后期（100w+）：赛事获客 + 生态锁定

### 核心策略

```
生态 = 赛事获客（新用户 onboarding） + 公益赛道（政策合规） + 投资对接（创业孵化）
```

### 具体动作

| 动作 | 参考案例 | 预算 | 优先级 |
|------|----------|------|--------|
| 举办年度大型综合赛事 | Trae AI 创造力大赛（¥890K） | 高 | P1 |
| 设蓝海赛道引导用户方向 | Trae：银发/非遗/公益 4 条赛道 | 中 | P1 |
| 设计"报名即奖"多段漏斗 | 报名→Pro月卡 / 提交→周边 / 复赛→曝光 | 中 | P1 |
| 邀请跨界领造官 × 技术评委双轨阵容 | Trae：4 领造官 + 7 评委交叉映射 | 中 | P2 |
| 对接投资机构/政府/高校资源 | Trae 决赛资源包 | 高 | P2 |

### 赛事设计速查

| 要素 | 建议 |
|------|------|
| 参赛强制条件 | 必须使用主办方工具完成作品（产品植入） |
| 学习资料 | 教程视频中产品教程占比 ≥ 50% |
| 多阶段激励 | ≥ 4 段（报名奖→提交奖→晋级奖→决赛奖），首段必须零门槛 |
| 总奖金池 | 目标人群 × ¥50-100 |
| 蓝海赛道比例 | 占总奖金 30-45%，奖金高出热门赛道 20-60% |
| 非现金亮点 | 生态曝光 + 导师对接 + 投资通道 |

### 关键原则

- **赛事 = 新用户完整 onboarding**：参赛者从 0 学到交出 Demo，比任何广告都有效
- **预算零增长**：蓝海赛道奖金通过内部再分配实现，不追加总预算
- **公益赛道是政策牌**：银发/非遗/无障碍赛道 = 政策合规 + 媒体曝光 + 竞争蓝海

## 五、全阶段持续投入项

无论处于哪个阶段，以下动作应持续进行：

| 动作 | 参考 | 频率 | 理由 |
|------|------|------|------|
| 技术博客深度输出 | Cursor Changelog | 月 ≥ 2 篇 | 长期信任资产，4 家中最被低估的策略 |
| 非现金资源池建设 | 导师库/合作机构/媒体渠道 | 季度更新 | 奖金花完就没了，资源池越滚越大 |
| 风险对策预演 | 利益分配/行为引导/复杂度降噪 | 每次大动作前 | 见 [optimization-patterns.md](optimization-patterns.md) §2 |

## 六、GTM 决策检查清单

项目启动/阶段切换时逐项勾选：

### 早期

- [ ] 是否有 ≥ 1 位行业技术大佬愿意公开推荐？
- [ ] 技术博客是否已启动（≥ 2 篇/月）？
- [ ] 是否有 1 个 30s 的惊艳 Demo 视频用于传播？
- [ ] 是否已在至少 2 个开发者社区建立了存在？

### 中期

- [ ] 是否有 ≥ 2 个知名企业客户可以公开案例？
- [ ] 定价是否分 3-4 档，每档差异直观可感知？
- [ ] Pro 功能独占是否让用户感觉"值得"而非"被勒索"？
- [ ] 是否已建立模板/示例市场降低新用户门槛？

### 后期

- [ ] 赛事规则是否强制参赛者使用主办方工具？
- [ ] 学习资料中产品教程占比是否 ≥ 50%？
- [ ] 多阶段激励是否 ≥ 4 段，首段零门槛？
- [ ] 蓝海赛道奖金是否高于热门赛道 20-60%？
- [ ] 领造官是否 ≥ 3 人、评委 ≥ 领造官 × 1.5？
- [ ] 是否有非现金资源（曝光/导师/投资）配套？
