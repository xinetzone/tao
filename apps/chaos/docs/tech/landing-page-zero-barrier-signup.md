## 设计注解

| 设计点 | 对应原则 | 作用 |
|--------|----------|------|
| 三步骤卡片 | ≤ 1 个可感知动作 | 用户一眼看完，脑中已有完整路径 |
| "审核只查格式" | 合规审核不评质量 | 消除"写得不够好"的心理障碍 |
| "3-5 分钟生成" | 工具使用 ≤ 5 分钟 | 零代码用户的核心疑虑被打消 |
| "确认领取"主动提醒 | 奖励须用户主动操作 | 防止"我明明过了怎么没奖励"的客服量 |
| 实时报名数 | 社交证明 | 强化"别人都报了"的从众心理 |
